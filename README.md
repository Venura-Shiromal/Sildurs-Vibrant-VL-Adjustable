# Sildurs Vibrant Shaders v1.281 Extreme-VL – Adjustable Volumetric Lighting

This is a modified version of **Sildurs Vibrant Shaders v1.281 Extreme-VL** (Extreme Volumetric Lighting) for Minecraft. The modification adds user‑adjustable controls for the volumetric lighting system, allowing you to fine‑tune the visual depth and performance impact of the light shafts and god rays.

## ✨ Features

- **Volumetric Lighting Distance (VL Distance)** – Control how far the volumetric light rays extend into the scene.
- **VL Max Samples** – Adjust the number of ray‑marching steps, trading quality for performance.
- All other original Sildurs Vibrant Shaders v1.281 features remain fully functional.
- Compatible with both **OptiFine** and **Iris** (on supported versions).

## 🎮 What Was Changed

In the original v1.281 Extreme-VL shader, the volumetric lighting parameters were fixed. This version exposes two key variables:

| Setting | Description |
|---------|-------------|
| **VL Distance** | The maximum distance (in blocks) that volumetric light rays are traced. Lower values improve performance, higher values create longer, more dramatic god rays. |
| **VL Max Samples** | The number of sampling steps per ray. Higher samples produce smoother, more detailed lighting but increase GPU load. Lower samples are faster but may introduce banding artifacts. |

These settings are now adjustable in‑game via the shader options menu. (Sky & Lighting > Volumetric Lighting)
